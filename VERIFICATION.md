## Practical limits

The environment blocked the preview browser, so visual rendering and interactive behavior at desktop/tablet/mobile sizes could not be browser-tested. Responsive breakpoints, 320px sizing, focus styles, reduced motion, menu logic, lightbox handling, review controls, FAQ disclosure, and map loading were reviewed in source. This is not a claim of a completed browser accessibility audit or real-device test. Run `npm run dev` to inspect the client presentation before publishing.

GitHub Actions and a live Pages URL were not executed or verified because no commit, push, repository change, or deployment was authorized. The public map’s embedded rendering likewise remains subject to Google and the visitor’s browser.

The terminal’s npm configuration emits an environment-level `http-proxy` deprecation notice. It is not generated by this project and does not prevent installation or building.
